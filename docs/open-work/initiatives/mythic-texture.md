# Initiative: mythic-texture

**Outcome:** the world has *weight beyond mechanics* — Calling events, fate, ceremony, death biographies, named landmark history, and the spirituality-driven narrative substrate that makes the colony feel mythopoeic rather than ergonomic.

## What counts

- Calling / fate event vocabulary expansion
- Ceremony / ritual systems that emerge from spirituality
- Post-death biography generation
- Named-event resolvers that produce mythic-texture continuity-canary contributions
- JointIntention as codified body language (the "first-class narrative texture" doctrine)

## What doesn't count

- Adding a stat to track ceremony attendance (that's `social-coordination` cluster, no initiative)
- UI for showing biographies (that's `tooling-diagnostics-ui`)
- Tuning corruption decay rates (that's `magic-mythic` cluster, balance work)

## Example tickets

- `133` §7.7.c Fate event-vocabulary expansion — Calling, destiny, fated-pair convergence
- `218` Ceremony richness from spirituality
- `137` Magic hard-gated at scoring
- `011` Cat-conversation rendering via Haiku
- `068` Post-death biographies via Claude API

## Canary signal

The **mythic-texture continuity canary** (≥1 named event per sim year) — see `CLAUDE.md` "Verification". A soak that posts mythic-texture: 0 collapses the survival lock. This initiative's tickets directly populate the continuity canary set.
