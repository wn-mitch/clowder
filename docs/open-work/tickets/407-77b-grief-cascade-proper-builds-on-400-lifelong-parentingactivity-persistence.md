## Why

400 ships the substrate FOUNDATION for grief: `ParentingActivity`
persists through kitten death; biases compute correctly; target-taking
finds nothing; the gap between persistent intent and absent recipient IS
grief, mechanically encoded (per memory
`project_lifecycle_endings_preserve_state`). This ticket adds the
EXPRESSION layer §7.7.b names — explicit mourning DSEs, vigil-at-grave
behaviors, decay rates specific to grief, narrative event emission for
death-event memorialization.

## Scope

- New DSE `Mourn` (or class of mourning DSEs) gated on
  `ParentingActivity.relationships` containing a dead-target entry
  (Caretake target-taking finds nothing → mourn fires as alternative
  expression).
- `vigil_at_grave` action: cat travels to deceased target's last-known
  position or burial tile, holds for a duration, emits a logged grief
  event.
- Grief decay rate: `parental_engagement` toward dead target decays
  faster than normal absence-decay (~2-3×) but still asymptotes to a
  small residual (~0.05 — "you never fully stop mourning a child").
- Named mythic-texture event on initial dead-target detection:
  `Feature::GriefBegan { mourner, deceased, name }`.
- Cross-archetype expression: tiger mother's grief expresses through
  Patrol-at-grave + Mourn; trad-wife mother's grief expresses through
  Vigil + Caretake-at-empty-tile; union-man father's grief expresses
  through Hunt-with-empty-target (provision but no recipient — food
  piles up); etc.
