## Why

Cats in real-world ethology develop idiosyncratic per-lineage behaviors
that propagate through proximity and family bonds — "this family stares
at the wall," "we groom in this specific sequence," "we sleep with one
paw out." These behaviors don't serve a functional purpose; they're
identity-marking practice that gets transmitted vertically (parent →
kitten) and laterally (between bonded partners). Substrate-wise, they
fit naturally as *modulators of existing actions* (rituals = how-you-do-
normal-things, not new actions) and propagate via the same
bond-multiplier infrastructure 400 uses for InLaw adoption.

Designed in 399's conversation; substrate slice large enough to warrant
its own ticket. Mythic-texture initiative tag: ritual events surface as
narrative-rich substrate; cats with shared rituals form observable
lineage texture.

## Scope

- New enum `RitualKind` with closed-with-parameters palette (~8-15
  variants):
  - `WallStare { tile_offset: (i8, i8) }` → IdleTargetDse modifier; pure
    texture
  - `GroomSequence { order: [BodyZone; 4] }` → GroomTargetDse modifier;
    pure texture
  - `BoxAffinity` → RestTargetDse modifier; small Rest recovery bonus
    (boxes are warmer, real ethology)
  - `WindowPerch { tile_offset: (i8, i8) }` → PatrolTargetDse modifier;
    small Threat-detection bonus
  - `LeftSideFood` → EatTargetDse modifier; pure texture
  - `NightYowl { tick_of_day_window: (u32, u32) }` → VocalizeTargetDse
    modifier; pure texture
  - `KneadingPreamble` → RestTargetDse modifier; tiny self-soothe bonus
  - `PawSleepOut` → RestTargetDse modifier; pure texture
- New Component `HasRitual(RitualKind)` (or `Vec<HasRitual>` if multi-
  ritual support) on cats.
- New Component `RitualWitness { counters: HashMap<discriminant(RitualKind), f32> }`
  for accumulating witness state on kittens (or any not-yet-acquired
  observer).
- Per-tick witness-accumulation system: for each observer with
  `RitualWitness`, iterate cats in tile-range with `HasRitual(K)`
  performing K's bound DSE; increment `counters[K] +=
  (observer.tradition + actor.tradition) × bond_multiplier(observer,
  actor) × base_rate`.
- Threshold crossing → insert `HasRitual(K)` marker on observer (parameters
  inherited from highest-contributing actor).
- `bond_multiplier` function shared with 400's InLaw adoption (single
  source of truth for kin/bond weighting): mother 3.0, JointIntention
  partner 2.5, father 2.0, sibling 1.5, non-kin 0.5.
- Per-RitualKind binding to existing target-DSEs (Idle, Groom, Rest,
  Patrol, Eat, Vocalize) with the appropriate modulation function.
- `teach_ritual_bias` formula (per 400's plan) boosts witness rate when
  parent in proximity to kitten (small Mentor-class lift).
