## Why

400 ships `ParentalKind::Adopted` as a declared variant on the
`ParentingActivity` Component but doesn't wire its adoption rule.
"Adopted" represents explicit colony-event-driven parental relationships
— specifically, orphan integration (a kitten whose biological mother
died is adopted by a non-kin colony member). This is distinct from
BondFormed (which accumulates over time without a triggering event):
Adopted fires on an explicit moment, often dramatic, and is permanently
remembered.

**Mythic-texture canary contributor** (per memory
`project_bondformed_adopted_mythic_texture`). Orphan integration events
are named (e.g., "<adopter> has taken in <orphan>") and count toward the
≥1-per-sim-year mythic-texture canary.

## Scope

- Detect orphan condition: kitten whose `KittenDependency.mother` Entity
  is `Dead` AND kitten's `parental_engagement` from any RelationshipTo
  source equals 0 (no surviving parent expressing engagement).
- Candidate scoring: for each living colony cat with high
  `(compassion + warmth)`, score eligibility weighted by proximity, age
  (adult preferred), existing ParentingActivity load (cats with many
  active dependents score lower).
- Adoption trigger: when one candidate's score exceeds threshold AND
  consensus from colony (Coordinator-elected directive, or simple
  majority of nearby adult cats), insert
  `RelationshipTo { target: orphan, kind: Adopted, bond_strength: 0.7,
  parental_engagement: 0.0, partner: None, ... }` on the adopter's
  ParentingActivity.
- Emit a named mythic-texture event:
  `Feature::OrphanAdopted { adopter, orphan, name: "..." }`. Naming:
  "<adopter> takes in <orphan>, who has no surviving mother."

## Out of scope

- Biological + InLaw adoption rules (ship in 400).
- BondFormed adoption rule (ticket 403; different trigger mechanism).
- Orphan substrate proper (this ticket assumes orphan-detection works
  from existing `KittenDependency.mother == Dead` query; if it doesn't,
  a small substrate prerequisite ticket may need to open).
- Adoption-failure narrative arcs (an orphan with no eligible adopters
  → starvation, etc. — handled by existing kitten-survival mechanics).
